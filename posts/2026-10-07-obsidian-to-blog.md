평소 메모는 옵시디언에 쌓아 두고, 블로그 글은 따로 파일을 만들어 옮기곤 했습니다. 같은 글을 두 번 다루는 게 번거로워서, **볼트에서 쓴 글을 그대로 블로그로 가져오는 흐름**을 만들었습니다.

## 어떻게 동작하나

1. 볼트의 `50_블로그` 폴더에서 블로그 글 템플릿으로 새 노트를 만듭니다.
2. 글을 다 쓰면 `slug`(주소에 쓰일 영문 이름)와 `description`을 채웁니다.
3. 블로그 폴더에서 가져오기 스크립트를 실행합니다.

```bash
python scripts/import_obsidian.py --dry-run   # 무엇을 가져올지 미리 보기
python scripts/import_obsidian.py             # 실제로 가져오기
```

## draft 체크박스의 의미

| draft | 뜻 | 스크립트 동작 |
| --- | --- | --- |
| 체크 안 됨 | 아직 업로드 전 | 블로그로 가져온다 |
| 체크됨 | 업로드 완료 | 건너뛴다 |

가져오기가 끝나면 스크립트가 노트의 `draft`를 자동으로 체크합니다. 그래서 몇 번을 실행해도 같은 글이 두 번 올라가지 않습니다.

> **블로그 태그는 따로**
> 볼트의 `tags`는 노트 정리용이라서, 블로그에 보일 태그는 `blog_tags`에 따로 적습니다.

## 옵시디언 문법은 어떻게 바뀌나

- `[[위키링크]]`는 링크 대신 일반 글자로 바뀝니다. 예: 볼트 사용법 → "볼트 사용법"
- `![[그림.png]]`처럼 넣은 그림은 블로그의 `assets` 폴더로 함께 복사됩니다.
- 콜아웃은 일반 인용문으로, `%%주석%%`은 지워진 채로 올라갑니다.

이제 글은 한 곳에서만 쓰고, 올리는 일은 명령어 한 줄로 끝납니다.
