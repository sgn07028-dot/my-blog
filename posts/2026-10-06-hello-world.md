안녕하세요! 이 블로그는 **마크다운 파일**을 읽어 웹페이지로 보여 줍니다. 빌드 과정 없이 브라우저가 글을 직접 불러와 변환해요.

## 새 글 쓰는 법

1. `posts/` 폴더에 `YYYY-MM-DD-slug.md` 형식으로 파일을 만듭니다.
2. 파일 맨 위에 front matter(제목, 날짜, 요약, 태그)를 적습니다.
3. `posts/posts.json`에 글 정보를 한 줄 추가합니다.

```json
{ "file": "2026-10-07-my-post.md", "title": "새 글", "date": "2026-10-07", "tags": ["일상"] }
```

## 로컬에서 보기

```bash
python -m http.server 8000
```

실행한 뒤 브라우저에서 `http://localhost:8000`으로 접속하면 됩니다.

> 오른쪽 위 버튼으로 다크 모드를 켜 보세요. 선택한 테마는 다음 방문 때도 유지됩니다.

어떤 문법을 쓸 수 있는지는 [마크다운 문법 가이드](#/post/markdown-guide)에 정리해 두었습니다.
